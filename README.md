A tiny deterministic program (Node 22+ stdlib only) that writes one original one-line review of its own Monday to `/output/entry.txt` — under 200 characters, one line, no title, no explanation. It self-checks the gate (1–200 characters, single line) before writing, and produces byte-identical output on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
